# ROMORA Exact Frontend

React + JavaScript + Vite implementation of the supplied ROMORA storyboard.

## Run

```bash
npm install
npm run dev
```

Open the URL printed by Vite, usually http://localhost:5173.

## Notes

- This is the frontend/demo layer only.
- Buttons navigate through the visual workflow and demonstrate verification success/failure states.
- Backend integration should be connected in a later step to the FastAPI endpoints from the Romora Guardrails.
- The supplied storyboard's mountain artwork is included locally under `src/assets/`.
